# 阿伟的 AI 冒险岛

以角色成长、蘑菇、金币、问号砖块、管道和浮空岛组成的 3D AI 博客。使用原创几何模型与 SVG 插画，主色为奶油白、草地绿、砖红和暖金色。

## 本地入口

- 首页：`http://127.0.0.1:8765/adventure/`
- 冒险手记：`http://127.0.0.1:8765/adventure/articles.html`
- 世界元素图鉴：`http://127.0.0.1:8765/adventure/elements.html`

在仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1` 即可预览，无需安装构建依赖。

## 页面与行为

- 真正的 3D 成长地图：五座浮空岛、村庄、树林、城堡、工坊、灯塔、管道和问号砖块。
- 拖动转动地图；点击标签、岛屿或章节卡选择章节，角色沿路线前往；支持重置视角。
- 环境持续运动：树叶与旗帜随风、云层漂移、流水与涟漪、烟雾、飞鸟、金币、风机、灯塔和角色行走。
- 全站动态开关同步 3D 地图与 CSS 动画，并保存用户偏好；遵循系统减少动态效果设置。
- 首页问号砖块可领取实践提示，金币弹出，提示连接到对应文章。
- 三个现有工具可筛选、站内打开、返回主页或独立打开；原有工具路径保持可用。
- 三篇工具手记、文章索引、文章目录、阅读进度与下一篇导航。
- 14 个原创立体 SVG 元素，已用于页面，并在图鉴中支持独立下载。
- 接入原有头像、个人微信、公众号、X 与邮箱；未编造项目交付或成长时间线。
- 支持桌面与手机；无 WebGL 时提供插画与章节入口；地图离开视口时停止绘制。

这是位于 `adventure/` 的本地版本，未替换原站首页或发布到线上。

## 文件

- `index.html`、`style.css`、`theme.css`：首页与全站主题。
- `app.js`、`scene.js`：首页交互与 3D 世界。
- `world-ui.js`：全站动态偏好、补给提示与阅读进度。
- `articles.html`、`articles/*.html`、`reading.css`、`shared-page.js`：博客索引与文章阅读。
- `elements.html`、`assets/*.svg`：原创 SVG 图鉴与资源。
- `vendor/three.module.js`：本地 Three.js 0.170.0。
